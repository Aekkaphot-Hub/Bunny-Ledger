## ความสามารถ
- **นำเข้าไฟล์จาก Seller Center** (Excel / CSV) ทั้งไฟล์คำสั่งซื้อและไฟล์รายได้/การโอนเงิน — เดาแพลตฟอร์มและคอลัมน์ให้อัตโนมัติ นำเข้าซ้ำได้ไม่ซ้ำซ้อน
- **ลูกหนี้แพลตฟอร์ม** — ออเดอร์ที่ลูกค้าได้รับของแล้วแต่เงินยังไม่เข้า แบ่งตามอายุหนี้ และแจ้งยอดโอนที่ผิดปกติ
- **ติดตามออเดอร์** — รอจัดส่ง / กำลังจัดส่ง / ส่งเกินกำหนดยังไม่ได้รับ / คืนสินค้า
- **ย้อนหลัง & สรุปยอด** — ปฏิทินรายวัน สรุปรายวัน รายสัปดาห์ รายเดือน และกราฟวงกลม (ยอดขายนับตาม **วันที่ส่งสินค้า**)
- **หลายร้านต่อ 1 บัญชี** — หลังเข้าสู่ระบบเลือกเปิดร้านที่สร้างไว้ หรือสร้างร้านใหม่ ข้อมูลแต่ละร้านแยกกัน
- **ทีมงาน** — เจ้าของร้านเชิญผู้จัดการ / พนักงานด้วยอีเมล ใช้ข้อมูลร้านเดียวกัน พนักงานไม่เห็นรายจ่ายและกำไร (บังคับสิทธิ์ที่ Firebase)
- **ต้นทุน & กำไรจริง** — ตั้งต้นทุนต่อ SKU จับคู่กับชื่อสินค้า+ตัวเลือกในออเดอร์ (เรียนรู้จากไฟล์ Excel ที่จดเองได้) แล้วคิดกำไรรายออเดอร์/รายเดือนให้
- **ออเดอร์มีปัญหา & เคลม** — หาออเดอร์ที่ร้านโดนเก็บค่าส่งเกิน น้ำหนักเกิน หรือตีกลับโดนหักค่าส่ง จากไฟล์รายได้ แล้วติดตามจนได้เงินคืน
- **เงินเข้าบัญชีธนาคาร** — ยอดถอนของ TikTok ยอดโอนรายวันของ Shopee รายสัปดาห์ของ Lazada ให้ติ๊กยืนยันว่าเงินถึงบัญชีจริง
- **รายจ่าย, รายรับอื่นๆ, ค่าธรรมเนียมแพลตฟอร์ม** (เรียนรู้อัตราที่ถูกหักจริงจากเงินเข้า)
- **ภาษี** — ติดตามเกณฑ์จด VAT 1.8 ล้าน + ประมาณ VAT รายเดือน • ประมาณภาษีเงินได้ ภ.ง.ด.94/90 (เทียบหักเหมา 60% กับหักตามจริง) • ปฏิทินภาษีพร้อมเตือนบนหน้าหลัก • ออกใบกำกับภาษีอย่างย่อ/เต็มรูป และรายงานภาษีขายรายเดือน
- **ส่งออก Excel** หลายชีต พร้อมรูปกราฟและสูตรรวม
- **เป็นแอป (PWA)** — ติดตั้งได้บนคอมและมือถือ ใช้งานออฟไลน์ได้
- **เก็บข้อมูล 3 ชั้น** — ในแอป • ไฟล์บนคอม (บันทึกอัตโนมัติ) • Firebase (ซิงก์หลายเครื่อง)

## เริ่มใช้งาน (Windows)
1. ดาวน์โหลดโปรเจกต์นี้ (Code → Download ZIP) แล้วแตกไฟล์
2. ดับเบิลคลิก `เปิดโปรแกรม.bat` → เปิดใน Edge / Chrome ที่ `http://localhost:8642`
3. กด **ติดตั้งแอป** มุมขวาบน เพื่อให้มีไอคอนบนเดสก์ท็อป
4. ลองกด **ลองข้อมูลตัวอย่าง** หรือนำเข้าไฟล์ใน `sample-data/`

ไม่ต้องติดตั้ง Node.js หรือโปรแกรมอื่น (ใช้ PowerShell ที่มากับ Windows เป็นเซิร์ฟเวอร์ในเครื่อง)

## ความเป็นส่วนตัว
- **ข้อมูลส่วนตัวของลูกค้า** (ชื่อ ที่อยู่ เบอร์โทร อีเมล เลขผู้เสียภาษี ข้อความจากผู้ซื้อ) ถูกตัดทิ้งทันทีตอนอ่านไฟล์ — ไม่ถูกเก็บในแอป ไม่ขึ้น Firebase ไม่อยู่ในไฟล์ Excel/ไฟล์สำรอง
- แอปส่งข้อมูลออกได้เฉพาะ Firebase ของร้านเท่านั้น (Content-Security-Policy) และ Firebase อนุญาตให้อ่าน/เขียนเฉพาะเจ้าของบัญชี (`firestore.rules`)
- เซิร์ฟเวอร์ในเครื่อง (`server.ps1`) เปิดให้เฉพาะเครื่องนี้ และส่งเฉพาะไฟล์ของแอป — ไฟล์ Excel/CSV/JSON ในโฟลเดอร์จะไม่ถูกเปิดผ่านเบราว์เซอร์
- `.gitignore` กันไม่ให้ไฟล์ Excel จริงและไฟล์ข้อมูลถูกอัปขึ้น GitHub
