## ความสามารถ
- **นำเข้าไฟล์จาก Seller Center** (Excel / CSV) ทั้งไฟล์คำสั่งซื้อและไฟล์รายได้/การโอนเงิน — เดาแพลตฟอร์มและคอลัมน์ให้อัตโนมัติ นำเข้าซ้ำได้ไม่ซ้ำซ้อน
- **ลูกหนี้แพลตฟอร์ม** — ออเดอร์ที่ลูกค้าได้รับของแล้วแต่เงินยังไม่เข้า แบ่งตามอายุหนี้ และแจ้งยอดโอนที่ผิดปกติ
- **ติดตามออเดอร์** — รอจัดส่ง / กำลังจัดส่ง / ส่งเกินกำหนดยังไม่ได้รับ / คืนสินค้า
- **ย้อนหลัง & สรุปยอด** — ปฏิทินรายวัน สรุปรายวัน รายสัปดาห์ รายเดือน และกราฟวงกลม
- **รายจ่าย, รายรับอื่นๆ, ค่าธรรมเนียมแพลตฟอร์ม** (เรียนรู้อัตราที่ถูกหักจริงจากเงินเข้า)
- **ส่งออก Excel** หลายชีต พร้อมรูปกราฟและสูตรรวม
- **เป็นแอป (PWA)** — ติดตั้งได้บนคอมและมือถือ ใช้งานออฟไลน์ได้
- **เก็บข้อมูล 3 ชั้น** — ในแอป • ไฟล์บนคอม (บันทึกอัตโนมัติ) • Firebase (ซิงก์หลายเครื่อง)

## เริ่มใช้งาน (Windows)
1. ดาวน์โหลดโปรเจกต์นี้ (Code → Download ZIP) แล้วแตกไฟล์
2. ดับเบิลคลิก `เปิดโปรแกรม.bat` → เปิดใน Edge / Chrome ที่ `http://localhost:8642`
3. กด **ติดตั้งแอป** มุมขวาบน เพื่อให้มีไอคอนบนเดสก์ท็อป
4. ลองกด **ลองข้อมูลตัวอย่าง** หรือนำเข้าไฟล์ใน `sample-data/`

ไม่ต้องติดตั้ง Node.js หรือโปรแกรมอื่น (ใช้ PowerShell ที่มากับ Windows เป็นเซิร์ฟเวอร์ในเครื่อง)
